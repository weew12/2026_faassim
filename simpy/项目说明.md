# simpy 包结构说明

`simpy` 是 faas-sim 的离散事件仿真子包。

SimPy 是一个基于标准 Python 的基于流程的离散事件仿真框架。SimPy 中的流程由 Python 生成器函数定义，例如，可用于模拟顾客、车辆或代理等活动组件。SimPy 还提供了各种类型的共享资源，用于模拟容量有限的拥塞点（例如服务器、收银台和隧道）。

模拟可以“尽可能快地”进行，也可以实时进行（实际时间），或者手动逐步执行事件。

虽然理论上可以使用 SimPy 进行连续模拟，但它并没有提供任何相关的功能。此外，对于步长固定且进程之间或进程与共享资源之间没有交互的模拟，SimPy 并非必需。

官方仓库：[https://gitlab.com/team-simpy/simpy](https://gitlab.com/team-simpy/simpy)

## 与 faas-sim 的关系

faas-sim 的 `sim.core.Environment` 继承并扩展了 `simpy.Environment`，把 FaaS 系统相关的"函数部署、实例生命周期、请求执行、自动伸缩、网络传输"全部挂载为 SimPy进程与事件。
