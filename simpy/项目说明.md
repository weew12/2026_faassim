# simpy 内置子包说明

`simpy/` 是 faas-sim 内置的离散事件仿真内核。它保留 SimPy 3.x 的公开接口，使项目中的 `import simpy` 不再依赖外部 pip 包，同时让源码和注释可以随 faas-sim 一起维护。

## 1. 这个包解决什么问题

SimPy 的核心思想是：用 Python 生成器表示“会随时间推进的过程”，用事件表示“未来某个时刻会发生的结果”。业务代码通过 `yield event` 暂停，事件完成后由环境恢复对应进程。

在 faas-sim 中，这套机制承载了：

- 函数副本部署和镜像拉取
- 容器启动、setup、teardown
- 请求到达、排队和函数执行
- 资源监控、自动伸缩和调度 worker
- Ether 网络流传输与中断重算

## 2. 阅读入口

建议从 `doc/00_README_目录索引.md` 开始。文档按源码依赖顺序组织：

1. 包入口与公开 API

4. `Interrupt` 异常模型
5. 实时环境与工具函数
6. 资源基类与三类资源实现

## 3. 与 faas-sim 的关系

faas-sim 的 `sim.core.Environment` 继承 `simpy.Environment`，在其上挂载 FaaS 系统对象、拓扑、调度器、资源状态和指标记录器。也就是说，faas-sim 的“业务环境”本质上仍然由 SimPy 的事件队列和仿真时钟驱动。

## 4. 版本说明

该目录来自 SimPy 源码，项目中已内置替代原来的外部 `simpy==3.0.11` 依赖。对调用方来说，接口仍然是标准写法：

```python
import simpy

env = simpy.Environment()
env.process(my_process(env))
env.run(until=10)
```

## 5. 维护原则

- 保持公开 API 与 SimPy 3.x 兼容。
- 源码注释面向阅读者解释机制，不把业务概念硬塞进内核。
- 文档关注源码路径、状态变化、事件顺序和常见误区。
- 如需扩展 faas-sim 行为，优先在 `sim/`、`ether/` 或 examples 中扩展，不轻易改变 SimPy 核心语义。
