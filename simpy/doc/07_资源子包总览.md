# 07 · 资源子包总览 resources/

> 对应源码：`simpy/resources/__init__.py`（11 行，**仅文档字符串，无代码**）
> 子包文件：`base.py` / `container.py` / `resource.py` / `store.py`

## 1. 子包职责

`resources/` 子包提供三类常用的**共享资源抽象**：

| 抽象 | 适用场景 | faas-sim 用途 |
| ---- | -------- | ------------- |
| `Resource` 系列 | 有限并发槽位（互斥锁/信号量/Priority/Preemptive） | 函数实例 worker 数、设备独占资源、连接池、GPU 等有限并发资源 |
| `Container` | 连续数值型容量 | 缓存空间、带宽令牌、资源预算等需要"生产/消耗"关系的仿真 |
| `Store` 系列 | 离散对象队列（FIFO / 优先级 / 过滤式） | 请求队列、消息队列、任务缓冲区、负载均衡器内部等待队列 |

> 注意：`resources/__init__.py` **没有**任何 import 或 `__all__`，它**不**做聚合导出。
> 所有公开资源都通过顶层 `simpy/__init__.py` 的显式 import 暴露（参见
> `01_simpy包入口.md`）。

## 3. 子包内部依赖关系

```
resources/base.py          # 独立：只依赖 core / events
    ↑
    ├── resources/container.py   # Container + ContainerPut/ContainerGet
    ├── resources/resource.py    # Resource 系列
    └── resources/store.py       # Store 系列
```

子类文件之间**没有**横向依赖，全部通过 `resources/base.py` 提供的统一抽象工作。

## 4. 通用 put/get 模型（所有资源的共同骨架）

每个资源子类都基于 `BaseResource` 的两阶段机制：

1. 业务进程调用 `resource.put(...)` 或 `resource.get(...)`，由 `BoundClass` 立刻
   构造对应的 `Put` / `Get` 事件（带 `resource`、`proc` 字段），并把事件挂到
   `put_queue` 或 `get_queue`。
2. 资源状态变化时，`_trigger_put` / `_trigger_get` 遍历对应队列，调用子类实现的
   `_do_put` / `_do_get`：
   - 若条件满足：更新资源状态、`event.succeed()`，从队列弹出。
   - 否则：保留在队列中等待。
3. `Put` / `Get` 事件本身**就是 `Event`**，所以进程 `yield resource.put(...)` /
   `yield resource.get(...)` 会挂起直到事件成功。

`Put` / `Get` 还实现了 `ContextManager` 协议（`__enter__` / `__exit__`），所以可以用
`with` 形式自动取消未触发的请求（参见 `08_资源基类base.md` 第 3 节）。

## 5. 通用字段（所有资源子类）

| 字段 | 类型 | 来源 | 说明 |
| ---- | ---- | ---- | ---- |
| `_env` | `Environment` | `BaseResource.__init__` | 资源所属仿真环境 |
| `_capacity` | `int/float` | `BaseResource.__init__` | 资源容量上限（语义由子类决定） |
| `put_queue` | `MutableSequence[PutType]` | `BaseResource.__init__` | 等待 put 条件满足的请求队列 |
| `get_queue` | `MutableSequence[GetType]` | `BaseResource.__init__` | 等待 get 条件满足的请求队列 |
| `capacity` | property | `BaseResource` | 只读容量上限 |

## 6. faas-sim 中的使用模式

```python
import simpy

env = simpy.Environment()

# 1) 槽位资源：函数实例并发槽
worker_pool = simpy.Resource(env, capacity=4)
with worker_pool.request() as req:
    yield req                       # 等到拿到槽位
    yield env.timeout(run_time)     # 跑函数

# 2) 连续容量：缓存水位
cache = simpy.Container(env, capacity=100, init=100)
yield cache.get(20)                # 消耗 20 单位
yield cache.put(5)                 # 归还 5 单位

# 3) 对象队列：请求队列
queue = simpy.Store(env, capacity=1000)
yield queue.put(req_obj)           # 入队
item = yield queue.get()           # 出队（FIFO）
```
