# 05 · 实时仿真 rt

对应源码：`simpy/rt.py`

## 1. 文件定位

`RealtimeEnvironment` 继承普通 `Environment`，在每次 `step()` 前等待真实墙钟时间，使仿真时间与现实时间按比例同步。

faas-sim 默认不使用实时环境，通常使用普通离散事件仿真，以尽可能快的速度跑完实验。

## 2. factor 的含义

`factor` 表示 1 个仿真时间单位对应多少真实秒。

| factor | 含义 |
| --- | --- |
| `1.0` | 仿真 1 秒对应真实 1 秒 |
| `0.001` | 仿真 1 秒对应真实 1 毫秒，仿真快 1000 倍 |
| `60` | 仿真 1 秒对应真实 60 秒，仿真放慢 |

## 3. step 的额外逻辑

普通 `Environment.step()` 直接处理下一个事件。实时环境会先计算该事件对应的墙钟时刻：

```python
real_time = real_start + (evt_time - env_start) * factor
```

然后 sleep 到这个时刻，再调用父类 `Environment.step(self)`。

## 4. strict 模式

`strict=True` 时，如果仿真执行速度落后墙钟超过一个 `factor` 单位，就抛出 `RuntimeError`。这可以避免业务逻辑太慢时仿真继续“假装实时”。

## 5. sync()

`sync()` 只重置 `real_start`，用于把当前仿真重新对齐到当前墙钟。它不重置 `env_start` 和 `env.now`。

## 6. 适用场景

适合：

- 数字孪生
- 与外部系统联调
- 需要人实时观察事件发生的演示

不适合：

- 大规模离线实验
- 参数扫描
- 论文批量跑数据
