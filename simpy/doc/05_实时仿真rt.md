# 05 · 实时仿真 rt

> 对应源码：`simpy/rt.py`（80 行）

## 1. 职责

`rt.py` 在普通离散事件环境基础上加入**墙钟时间同步**能力。它实现
`RealtimeEnvironment`，让仿真时间按指定 `factor` 映射到真实时间。faas-sim 当前**默认
采用普通离散事件仿真**；本类为后续做数字孪生、在线协同仿真或与外部系统对齐时保留入口。

## 2. 类继承关系

```
core.Environment
└── rt.RealtimeEnvironment
```

## 3. `RealtimeEnvironment`

### 3.1 构造

```python
class RealtimeEnvironment(Environment):
    def __init__(
        self,
        initial_time: SimTime = 0,
        factor: float = 1.0,
        strict: bool = True,
    ):
        Environment.__init__(self, initial_time)
        self.env_start = initial_time          # 仿真起始时间
        self.real_start = monotonic()          # 真实墙钟起始时间
        self._factor = factor                  # 仿真→真实换算因子
        self._strict = strict                  # 是否在落后时抛错
```

| 参数 | 类型 | 默认 | 含义 |
| ---- | ---- | ---- | ---- |
| `initial_time` | `SimTime` | `0` | 仿真起始时间 |
| `factor` | `float` | `1.0` | 一个仿真时间单位对应的真实秒数 |
| `strict` | `bool` | `True` | 仿真落后墙钟超过 `factor` 秒时是否抛 `RuntimeError` |

### 3.2 属性

| 属性 | 含义 |
| ---- | ---- |
| `factor` | 仿真→真实换算因子 |
| `strict` | 是否启用严格模式 |

### 3.3 方法

#### `sync()`

把"真实墙钟起始时间"重新对齐为当前 `monotonic()`：

```python
def sync(self):
    self.real_start = monotonic()
```

适用场景：跑了一段时间后想重新对齐基准（如刚执行完一段非仿真逻辑、需要把仿真重新拉回
墙钟节奏）。

#### `step()` —— 核心覆盖

```python
def step(self):
    evt_time = self.peek()
    if evt_time is Infinity:
        raise EmptySchedule

    real_time = self.real_start + (evt_time - self.env_start) * self.factor

    if self.strict and monotonic() - real_time > self.factor:
        delta = monotonic() - real_time
        raise RuntimeError(f'Simulation too slow for real time ({delta:.3f}s).')

    while True:
        delta = real_time - monotonic()
        if delta <= 0:
            break
        sleep(delta)

    Environment.step(self)
```

逐步解释：

1. 取下一个事件时间 `evt_time`。若队列空，抛 `EmptySchedule`。
2. 计算它应该触发的墙钟时刻 `real_time = real_start + (evt_time - env_start) * factor`。
3. `strict=True` 且当前墙钟已经超过 `real_time` 一个 `factor` 以上，说明仿真跑得太
   慢，立即 `raise RuntimeError('Simulation too slow for real time (...)')`，避免
   后续 sleep 出现负数陷入忙等。
4. 否则循环 `sleep` 直到墙钟到达 `real_time`，调用父类 `Environment.step(self)`
   处理该事件。

> 注意：父类 `Environment.step()` 仍然负责推进 `_now`、执行回调、维护事件队列，
> 本类只在外层加了一段"等墙钟"逻辑。

## 4. faas-sim 衔接

faas-sim 当前**未直接使用** `RealtimeEnvironment`。其仿真主循环默认基于
`sim.core.Environment`（继承自 `simpy.Environment`），跑得比真实时间快几个数量级。
如果后续要做：

- 在线 FaaS 调度实验（接真实 K8s）
- 数字孪生演示
- 与人工观察 / 控制系统联调

可以切换 `env = simpy.RealtimeEnvironment(initial_time=0, factor=0.001, strict=True)`
来把仿真节奏放慢到合适速度。

## 5. 与 `factor` 的换算示例

| `factor` | 1 仿真单位 = ? 真实秒 | 适用 |
| -------- | ---------------------- | ---- |
| `1.0`    | 1.0 s                  | 1:1 同步 |
| `0.001`  | 1 ms                   | 仿真 1s 等于真实 1ms（快 1000 倍） |
| `60.0`   | 60 s                   | 仿真加速（每个仿真单位对应一分钟） |
