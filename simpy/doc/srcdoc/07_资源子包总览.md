# 07 · 资源子包总览

对应源码：`simpy/resources/__init__.py`

## 1. 文件定位

`resources/` 提供共享资源模型。资源请求也是事件：当资源条件满足时，请求事件成功，等待它的进程继续执行。

## 2. 三类资源

| 资源 | 文件 | 模型 | 典型用途 |
| --- | --- | --- | --- |
| `Resource` | `resource.py` | 有限并发槽位 | worker 池、互斥锁、连接池 |
| `Container` | `container.py` | 连续容量水位 | 缓存容量、令牌桶、预算 |
| `Store` | `store.py` | 离散对象队列 | 请求队列、消息队列、任务缓冲 |

## 3. 共同机制

三类资源都基于 `base.py` 的 put/get 框架：

```text
请求创建
  -> 进入 put_queue 或 get_queue
  -> 资源尝试 _do_put / _do_get
  -> 条件满足则 event.succeed(...)
  -> 等待进程恢复
```

## 4. faas-sim 中怎么用

- FaaS 请求排队：`Store`
- 函数副本 worker 并发：`Resource`
- 优先级或抢占：`PriorityResource` / `PreemptiveResource`
- 缓存容量或预算：`Container`

## 5. 入口说明

`resources/__init__.py` 只做子包说明，不聚合导出。公开对象由顶层 `simpy/__init__.py` 显式导出。
