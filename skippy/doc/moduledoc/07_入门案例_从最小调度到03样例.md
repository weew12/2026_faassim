# 入门案例：从最小调度到 03 样例

## 最小 Skippy 调度案例

下面是一个最小概念示例，展示如何直接使用 Skippy 调度器。

```python
from skippy.core.clustercontext import ClusterContext
from skippy.core.model import (
    Node, Capacity, Pod, PodSpec, Container,
    ResourceRequirements, ImageState,
)
from skippy.core.scheduler import Scheduler
from skippy.core.storage import StorageIndex


class DemoContext(ClusterContext):
    def __init__(self):
        self._nodes = [
            Node(
                "edge-0",
                capacity=Capacity(cpu_millis=2000, memory=2 * 1024 * 1024 * 1024),
                allocatable=Capacity(cpu_millis=2000, memory=2 * 1024 * 1024 * 1024),
                labels={
                    "beta.kubernetes.io/arch": "amd64",
                    "locality.skippy.io/type": "edge",
                },
            ),
            Node(
                "cloud-0",
                capacity=Capacity(cpu_millis=8000, memory=8 * 1024 * 1024 * 1024),
                allocatable=Capacity(cpu_millis=8000, memory=8 * 1024 * 1024 * 1024),
                labels={
                    "beta.kubernetes.io/arch": "amd64",
                    "locality.skippy.io/type": "cloud",
                },
            ),
        ]
        super().__init__()
        self.storage_index = StorageIndex()

    def get_init_image_states(self):
        return {
            "demo:latest": ImageState({"amd64": 100 * 1000 * 1000})
        }

    def get_bandwidth_graph(self):
        return {
            "registry": {"edge-0": 10 * 1000 * 1000, "cloud-0": 100 * 1000 * 1000},
            "edge-0": {"edge-0": 125 * 1000 * 1000, "cloud-0": 20 * 1000 * 1000},
            "cloud-0": {"edge-0": 20 * 1000 * 1000, "cloud-0": 125 * 1000 * 1000},
        }

    def list_nodes(self):
        return self._nodes

    def get_next_storage_node(self, node):
        return None


context = DemoContext()
scheduler = Scheduler(context)

spec = PodSpec(
    containers=[
        Container(
            "demo:latest",
            ResourceRequirements({"cpu": 500, "memory": 256 * 1024 * 1024}),
        )
    ],
    labels={},
)
pod = Pod("pod-demo-1", "faas-sim", spec)

result = scheduler.schedule(pod)
print(result.suggested_host)
print(result.feasible_nodes)
print(result.needed_images)
```

这个例子展示了 Skippy 最小依赖：

- 节点列表；
- 镜像大小；
- 带宽图；
- Pod 资源请求；
- Scheduler。

## 03 样例演示什么

`03_skippy_scheduler` 用于演示：

- faas-sim 如何调用 Skippy 默认调度器；
- Skippy 如何执行资源过滤；
- 可行节点集合如何变化；
- 每个 Pod 最终调度到哪个节点；
- 镜像缓存复用如何影响 `needed_images`；
- 调度结果如何导出 CSV；
- 图表如何展示调度行为。

## 如何读 03 样例输出

重点看三类信息。

第一类：调度结果。

```text
pod_name
selected_node
feasible_nodes
needed_images
```

它回答“这个 Pod 被放到哪里，为什么可能需要拉镜像”。

第二类：候选节点。

```text
pod_name
node_name
cpu_allocatable
memory_allocatable
predicate_passed
```

它回答“哪些节点可行，哪些节点被过滤”。

第三类：一致性检查。

```text
schedule_probe_invocation_join
invoke_probe_invocation_join
self_check
```

它回答“调度、请求分发、函数调用是否能对上”。
