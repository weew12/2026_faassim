# `examples` 包结构说明

示例包：展示不同扩展点的最小可运行使用方式。

## 包内 Python 文件

- `__init__.py`：该文件参与本包对应的仿真支撑逻辑。

## 子目录

### 官方原始示例包

1. `basic/`：基础示例包：展示标准 Simulation + Benchmark 工作流。
[examples/basic](./basic/readme.md)

2. `custom_function_sim/`：自定义函数模拟器示例包。
[examples/custom_function_sim](./custom_function_sim/readme.md)

3. `analysis/`：结果分析示例包。
[examples/analysis](./analysis/readme.md)

4. `custom_scheduler/`：自定义调度器示例包。
[examples/custom_scheduler](./custom_scheduler/readme.md)

5. `watchdogs/`：watchdog 执行模式示例包。
[examples/watchdogs](./watchdogs/readme.md)

6. `request_gen/`：请求生成器示例包。
[examples/request_gen](./request_gen/readme.md)
