# `examples` 包结构说明

示例包：展示不同扩展点的最小可运行使用方式。

## 包内 Python 文件

- `__init__.py`：该文件参与本包对应的仿真支撑逻辑。

## 子目录

- `analysis/`：结果分析示例包。
- `basic/`：基础示例包：展示标准 Simulation + Benchmark 工作流。
- `custom_function_sim/`：自定义函数模拟器示例包。
- `custom_scheduler/`：自定义调度器示例包。
- `request_gen/`：请求生成器示例包。
- `watchdogs/`：watchdog 执行模式示例包。
