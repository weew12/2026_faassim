# 01 · 包入口与一级目录概览

> 本文档解析 `ether` 包的包入口文件,以及一级目录下的所有代码文件的清单与依赖关系。

## 1. 包入口 `__init__.py`

**位置**:`ether/__init__.py`
**行数**:2

### 完整内容

```python
"""Ether 内置网络拓扑子包入口。该包被 faas-sim 作为本地依赖使用,
负责构建边缘/云网络拓扑、节点、链路、网络单元和流式带宽仿真。"""
```

### 解析

- 仅有一行 docstring,**没有任何导入或运行时代码**
- 说明 ether 是 **faas-sim 的本地依赖子包**(对应官方仓库 `edgerun/ether`)
- 职责定位:**构建边缘/云网络拓扑、节点、链路、网络单元和流式带宽仿真**

### 备注

- 各个子模块(`core.py`、`cell.py` 等)需要用户**显式 import** 才生效,例如:

  ```python
  from ether.core import Node, Flow
  from ether.cell import LANCell, SharedLinkCell
  ```

- 没有任何 `__all__` 声明,意味着 `from ether import *` 会按 Python 默认规则(全部非下划线开头符号)导入所有

## 3. 一级目录间的依赖关系

```
                ┌──────────────┐
                │  __init__.py │  (空,只声明包)
                └──────┬───────┘
                       │
       ┌───────────────┼───────────────┐
       │               │               │
       ▼               ▼               ▼
  ┌─────────┐    ┌──────────┐    ┌──────────┐
  │ core.py │◄───┤ cell.py  │    │topology  │
  │         │    │          │    │   .py    │
  │ (基础)  │    │ (DSL)    │    │          │
  └────┬────┘    └────┬─────┘    └────┬─────┘
       │              │               │
       │              │               │
       │         ┌────▼─────┐    ┌────▼──────┐
       │         │ util.py  │    │vivaldi.py │
       │         │(被 core  │    │           │
       │         │ 被 node  │    │           │
       │         │ 引用)    │    │           │
       │         └──────────┘    └───────────┘
       │
       │
  ┌────▼──────┐    ┌──────────┐
  │ export.py │    │  vis.py  │
  │(引用 core │    │(引用 core│
  │ topology) │    │ Link Node)│
  └───────────┘    └──────────┘
```

**依赖箭头说明**:

- `cell.py` → `core.py`、`topology.py`、`qos` —— DSL 拼装基础类型
- `topology.py` → `core.py`、`inet.graph` —— 在 DiGraph 上包装 Node/Link
- `util.py` → 无(纯 stdlib)
- `export.py` → `topology.py`、`core.py`
- `vis.py` → `core.py`(Node/Link 类型判断)
- `vivaldi.py` → `core.py`(实现 Coordinate 抽象)

## 5. 各文件的"用户接触频率"

| 文件 | 接触频率 | 接触场景 |
|---|---|---|
| `core.py` | **高** | 写仿真逻辑、扩展调度器 |
| `cell.py` | **高** | 搭场景、自定义单元 |
| `topology.py` | **高** | 查 RTT、加载云区域图 |
| `vivaldi.py` | 中 | 轻量 RTT 估算 |
| `util.py` | 低 | 一般不直接调,通过 `blocks/nodes.py` 间接用 |
| `export.py` | 低 | 偶尔导出数据 |
| `vis.py` | 低 | 偶尔画拓扑预览图 |
